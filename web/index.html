    Context Meter
    • source
    • docs
    
        
    
          
    How full the session's context window is, right above the prompt at its right end: dim while there is room, yellow from 50% when it is a good moment for /compact, and red from 75% when a new session is better. After a resume, compaction or rewind it estimates the window (context ~16%) until the next response.

    Narrator
    • source
    • docs
    
        
    
          
    Click ⏸︎ narrator off at the bottom right, or type /narrator, and after each turn Claude tells you out loud what it did, in the language you wrote in, with the best free voice your system has: Siri's on macOS, Narrator's on Windows, speech-dispatcher's on Linux. While it speaks the switch reads ⏹︎ narrating, and a click stops it.

    Time Machine
    • source
    • docs
    
        
    
          
    Every turn that changes files is a git snapshot off your history, Bash changes included, in an index of its own so your staging area, HEAD and branches stay untouched. Type /timeline to browse every state (◉ current, ○ undone), preview what would change and jump back or forward without losing unsaved edits.
